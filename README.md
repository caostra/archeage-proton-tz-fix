# 아키에이지 크로니클 Steam Deck 실행 오류 임시 해결 도구

아키에이지 크로니클 실행 시 다음 오류가 발생하는 분을 위한 **비공식·실험용 Proton 패치 도구**입니다.

> `SystemTimeToTzSpecificLocalTimeEx` 함수를 `KERNEL32.dll`에서 찾을 수 없다는 오류

Steam Deck에서 **게임 모드 시작 화면까지 진입한 패치**를 적용합니다. 서버 접속, 실제 플레이, 장시간 안정성 및 안티치트의 지속적인 허용 여부는 아직 확인하지 않았습니다.

## 꼭 확인해 주세요

- **검증한 특정 Proton Experimental 빌드만 지원합니다.** 같은 이름의 Experimental이라도 업데이트 시점이 다르면 적용되지 않습니다.
- 지원하지 않는 버전이라고 나오면 중단해 주세요. 파일명이나 해시를 바꿔 강제로 적용하지 마세요.
- 게임 전체를 복사하지 않습니다. **Proton만 별도로 복사하므로 약 1.5~2GB 이상의 여유 공간**이 필요합니다.
- 원본 Proton, 게임 실행 파일, 안티치트 파일은 수정하지 않습니다.
- 정식 수정이 아닌 시간 변환 함수의 임시 우회이며, 모든 시간대·서머타임 동작을 완전히 구현하지는 않습니다.
- 관리자 권한이나 `sudo`, 추가 Python 패키지 설치는 필요하지 않습니다.

## 설치 방법

### 1. 압축 풀기

Steam Deck을 **데스크톱 모드**로 전환하고, 받은 `ArcheAge-Proton-TZFix-0.1.0.zip`을 압축 해제합니다.

`archeage_proton_fix.py`가 있는 폴더에서 터미널을 여세요. 파일 관리자에서 폴더를 우클릭해 **터미널 열기**를 사용할 수 있습니다.

### 2. 지원 여부 확인

다음 명령을 입력합니다.

```bash
python3 archeage_proton_fix.py check
```

이 단계에서는 파일을 변경하지 않습니다.

**지원하는 버전과 DLL이라는 안내가 나온 경우에만** 다음 단계로 진행해 주세요. 버전 불일치로 중단되면 현재 설치된 Proton은 이 도구의 지원 대상이 아닙니다.

### 3. 패치 도구 설치

```bash
python3 archeage_proton_fix.py install
```

표시되는 원본·복사본 경로와 용량을 확인한 뒤, 진행하려면 `y`를 입력합니다.

도구가 Proton을 별도로 복사하고, 백업·패치·결과 검증을 수행합니다. 이미 같은 이름의 설치 폴더가 있으면 덮어쓰지 않습니다.

### 4. 게임 모드에서 선택

Steam을 완전히 재시작하거나 Steam Deck을 재부팅한 뒤 다음과 같이 설정합니다.

1. **게임 모드 → 아키에이지 크로니클**
2. **톱니바퀴 → 속성 → 호환성**
3. **특정 Steam Play 호환 도구 강제 사용** 활성화
4. **Proton Experimental (ArcheAge TZ Fix 20261104)** 선택
5. 기존 라이브러리에서 **플레이**

별도 게임을 추가하거나 데스크톱 실행 아이콘을 만들 필요는 없습니다. 첫 실행에는 셰이더 준비가 오래 걸릴 수 있습니다.

계정 등록·이용약관·개인정보 동의 화면이 나타나면 내용을 확인하고 직접 결정해 주세요.

## 설치 상태 확인

압축을 풀었던 폴더에서 실행합니다.

```bash
python3 archeage_proton_fix.py status
```

설치된 패치 DLL과 백업의 해시를 검사합니다.

## 되돌리기·제거

패치 사용을 중단하려면 게임을 종료하고, **게임 속성 → 호환성**에서 기존 Proton을 선택하면 됩니다. 기존 Proton에서는 원래 DLL 오류가 다시 발생할 수 있습니다.

패치 Proton 폴더도 삭제하려면 다른 Proton을 선택한 다음 **Steam을 완전히 종료**하고 실행하세요.

```bash
python3 archeage_proton_fix.py remove
```

이 도구가 만든 Proton 복사본만 제거합니다. 원본 Proton이나 게임·저장 데이터는 삭제하지 않습니다.

## 문제가 생기면

- **버전 불일치:** 지원하지 않는 빌드입니다. 강제 적용하지 마세요.
- **호환 도구 목록에 없음:** Steam을 완전히 종료한 뒤 다시 실행하거나 재부팅해 주세요.
- **이미 설치되어 있음:** `status`로 확인해 주세요. 기존 폴더를 임의로 덮어쓰지 마세요.
- **제거가 거부됨:** 다른 Proton을 선택하고 Steam과 게임을 모두 종료했는지 확인해 주세요.
- **DLL 오류 이후 다른 문제가 발생함:** 이 도구는 게임의 모든 호환성 문제를 해결하는 패치가 아닙니다.

문제를 공유할 때는 SteamOS 버전, `check` 결과, 오류 문구와 어느 화면까지 진행됐는지 알려 주세요. 비밀번호·계정 정보는 보내지 마세요.

※ 별도 복사한 Proton은 Steam의 Experimental 업데이트를 자동으로 따라가지 않습니다. 다른 빌드를 지원하려면 별도 검증과 도구 업데이트가 필요합니다.
